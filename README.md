# Matru Sneh App

## 📱 Project Overview

Matru Sneh is an Android app. It helps with care and health monitoring. The app lets users track health information. It also helps users and healthcare providers talk to each other better.

## 🚀 Features

- 👩‍⚕️ The app is easy to use.

- 📋 Users can track their health information.

- 🔐 The app has secure login and authentication.

- 📊 It uses Firebase to store data.

- 📱 Users get real-time updates. Can access their data.

## 🎯 Problem Statement

Many people do not have access, to organized maternal health information. They also lack tracking systems. This leads to monitoring and communication.

Matru Sneh solves this problem. It provides a platform. Users can. Access their health data efficiently on this platform. Matru Sneh app helps users track their health.

## 🛠️ Technologies Used

- Kotlin

- XML

- Android Studio

- Firebase Authentication

- Firebase Realtime Database
